# Market Outlook USA

Landing page per una newsletter mensile sui mercati americani, con un **calcolatore DCF** interattivo (crescita a 5 anni + valore terminale di Gordon).

**Demo live:** https://tahabahousse.github.io/market-outlook-usa/

## Cosa contiene
- Hero e sezione "metodo" (Macro, Mercati, Da guardare)
- Calcolatore DCF: free cash flow, crescita, WACC, debito netto → tabella dei flussi scontati, enterprise value ed equity value
- Controllo di coerenza: avvisa se il WACC non supera la crescita di lungo periodo
- Form di iscrizione dimostrativo (non salva dati)

## Tecnologie
HTML, CSS e JavaScript puro, nessuna dipendenza. Pubblicato con GitHub Pages.

## Nota
Progetto personale di Taha Bahousse, realizzato con il supporto di strumenti di AI. Strumento didattico, non è un consiglio di investimento.
